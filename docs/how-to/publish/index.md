# Publish

> Queue a post, preview it, publish it, reply, and amplify.


Add posts to the queue, preview them with a dry run, publish them to several profiles at once, and amplify what worked: reposts, retweets, quotes, upvotes, and GitHub reactions. Reply and comment from the queue too. For YouTube uploads, Posts-tab posts, comments, replies and likes, see [Post to YouTube](/docs/how-to/publish/post-to-youtube/).
