# Integrations

> Every platform Blowhorn reaches. LinkedIn, X, Reddit, Hacker News, YouTube and more through your own browser, with YouTube uploads, comments, replies and likes going through YouTube's official API after Data API consent. Slack and Bluesky through their APIs. GitHub reactions on issues, never posts.
